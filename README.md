# 📞 Call Center Performance Dashboard (Excel)

## 📌 Project Overview

The **Call Center Performance Dashboard** is an interactive Microsoft Excel dashboard developed to analyze customer service operations and provide actionable business insights. The dashboard enables managers to monitor call performance, customer satisfaction, sales generated through calls, and representative productivity in a single view.

This project demonstrates advanced Excel analytics techniques including Pivot Tables, Pivot Charts, Slicers, Data Modeling, Conditional Formatting, and Dashboard Design.

---

# 🎯 Business Problem

Call centers generate thousands of customer interactions every month. Without proper reporting, managers face challenges such as:

- Difficulty tracking customer satisfaction.
- Identifying low-performing representatives.
- Monitoring sales generated from customer calls.
- Analyzing customer demographics.
- Understanding call trends over time.

This dashboard solves these challenges by converting raw operational data into meaningful visual insights.

---

# 🚀 Objectives

- Analyze overall call center performance.
- Monitor customer satisfaction ratings.
- Track purchase amounts generated from calls.
- Measure representative productivity.
- Identify customer demographics.
- Provide interactive filtering for quick decision making.
